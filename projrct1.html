About FlavorBox

FlavorBox is a small web application for sharing and managing recipes. Users can browse recipes, view details, and add new recipes that are stored locally in the browser. The project emphasizes clean UI, straightforward UX flows, and responsive design.

  • Type: Web Application (Recipes)
  • Tools: HTML, CSS, JavaScript, localStorage
  • Year: 2025

Problems & Solutions

Challenges faced while building FlavorBox and how they were solved.

1. Uneven card heights in the grid

Problem: Recipe cards had different heights due to varying description lengths.

Solution: Applied flexbox/grid with fixed image heights and text truncation to keep cards uniform.

2. Lost user recipes after refresh

Problem: Recipes added by the user disappeared when the page reloaded.

Solution: Implemented localStorage-based saving so recipes persist between sessions.

3. Responsive image cropping

Problem: Images were being cropped oddly across different screen sizes.

Solution: Used object-fit: cover; and consistent aspect ratios for all recipe thumbnails.
