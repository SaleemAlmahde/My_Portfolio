Keep Notes App

About Keep Notes App

Keep Notes App helps users capture ideas, tasks, and lists efficiently. It supports two note types — simple text notes and checklist notes — with intuitive design and seamless saving. The project focuses on usability, minimal UI, and efficient state management using Cubit.

  • Type: Mobile App (Note Taking)
  • Tools: Flutter, Dart, Cubit, SharedPreferences
  • Year: 2025

Problems & Solutions

Challenges faced while building the Keep Notes App and how they were solved.

1. Managing multiple note types

Problem: Handling both text notes and checklist notes within the same app logic caused state confusion.

Solution: Used separate models (TextNoteModel and CheckListNoteModel) while keeping all managed under a unified NotesCubit for simplicity.

2. State not updating immediately

Problem: The UI didn’t always refresh when adding or editing notes.

Solution: Used Cubit’s emit() method effectively and ensured data updates before rebuilding the interface.

3. Data loss after closing the app

Problem: Notes disappeared after restarting the app.

Solution: Implemented SharedPreferences to persist note data locally, ensuring notes are saved even after app closure.

4. UI inconsistencies between note types

Problem: Checklist notes and text notes had different paddings and spacing.

Solution: Unified visual design through reusable widgets and consistent margin/padding styles.
