About Property in Homs

Property in Homs is a modern real estate app that helps users find properties for rent or sale in Homs. It connects to the Back4App API to fetch property data dynamically, supports image previews, and allows users to filter listings by price, location, and type. The project emphasizes API integration, clean architecture, and team collaboration.

  • Type: Real Estate Mobile App
  • Tools: Flutter, Dart, Cubit, Bloc, Back4App
  • Year: 2025
  • Team Project: Developed collaboratively by multiple developers

Problems & Solutions

Challenges faced while building the Property in Homs app and how the team solved them.

1. API Integration and Data Handling

Problem: Fetching and displaying property data from Back4App while keeping performance stable.

Solution: Used Dio for API requests and implemented Cubit/Bloc to manage state efficiently.

2. Filtering and Searching Properties

Problem: Implementing dynamic filters (location, type, and price range) caused UI delays.

Solution: Optimized queries and updated filters with debounced Cubit logic for smoother performance.

3. Image Loading and Display

Problem: Property images loaded slowly and sometimes failed to appear.

Solution: Added caching and fallback placeholders to ensure stable image display even with weak connections.

4. Team Collaboration

Problem: Merging code and maintaining consistent structure between multiple developers.

Solution: Followed clean architecture principles and clear folder structure for easier integration.
